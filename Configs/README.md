# Configs

Non-Codex local agent tool configuration and setup bundles live here. Prefer
keeping reusable instructions in `Skills/`, `Workflows/`, `Plans/`, `MCP/`, or
`Subagents/`; use this folder for the tool-specific files that make those
systems run on a machine.

Keep secrets, auth files, caches, sessions, logs, and runtime databases out of
this folder.
