# Codex

Codex-specific local setup lives here.

- `Configs/`: Codex configuration. On this host, `~/.codex/config.toml` points to
  `Codex/Configs/config.toml`.
- `Plugins/`: local Codex plugin source directories plus marketplace metadata.

Do not store Codex auth files, session logs, caches, local history, or runtime
databases here.
